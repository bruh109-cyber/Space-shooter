# Space Shooter (PICO-8)

Small vertical space shooter game created in [PICO-8](https://www.lexaloffle.com/pico-8.php). Control your ship, destroy the approaching enemies, live as long as you can, get a high score.

## Controls

| Button | Keyboard | Action |
|---|---|---|
| ◀ ▶ ▲ ▼ | Arrow keys | Move the ship |
| ❎ (X) | `X` | Shoot |
| 🅾️ (O) | `Z` | Restart after game over |
| Pause | `P` or `Enter` | Pause menu |

## How to play

- Navigate around the screen and shoot the enemies.
- Every enemy must be shot two times. You earn **10 points** for every defeated enemy.
- Colliding with an enemy costs you **1 life**. You have **3 lives**.
- After being hit, you become invincible for 1.5 seconds (the ship will blink).
- More time spent on living, more quickly new enemies appear.

## Features

- Parallax scrolling background with the stars (3 layers deep)
- Lists of bullets and enemies with collision detection
- Shooting cooldown (around 7.5 shots per second)
- Explosions, screen shake and hit flash effect
- Lives, score and game over screen
